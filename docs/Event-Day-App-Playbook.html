03

The one rule of the reveal

Hands first, screen second. Ameen still asks for hands in the debrief. Then the screen shows the exact number as the punch: "You saw the hands — here is the truth: 78% of this room can't state the problem they solve." The screen amplifies the moment; it never replaces the hands.

Stage mode shows one big stat per question (the share who chose a weaker answer) with that line ready to read. Toggle it with the Stage mode button or the S key; move sections with the arrow keys.

05

The buying window — two programs, live names

  • Two programs sell: Guided Mode (the 8-seat scarcity hero) and Solo Mode (the ~25 downsell). Payment is on-spot UPI.
  • When someone pays, the payment team finds them in Records (use the search box), and taps G (Guided) or S (Solo) in their row.
  • The big screen updates within seconds: "N left of 8" for Guided, the Solo count, and the real names of who just joined — live social proof.
  • To change capacity, edit the target box on the Guided or Solo card (e.g. 8 to 10).
Where to update the seats

Records page → the Live enrollments card and the G / S buttons in each row. "Seats left" on the room screen is just target − enrolled. Tap on a tablet; Ameen stays on stage.

Quick reference

  • Keyboard (Live answers): ← → sections · S stage mode.
  • Deep link a view: /room/live?key=…§ion=4&stage=1
  • Update seats: Records → Live enrollments card + G/S per row.
  • Find a buyer fast: Records → search box (name/email/phone).
  • Allow retakes for arrival/end-of-day pulses: Records → toggle, then off.
  • Follow-up: "copy" per row, or Export CSV for all.
